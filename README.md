# Codex夜間運用プランナー PWA

Codexの週間残量・短時間枠・作業内容から、寝る前に回す作業規模を提案するスマホ対応Webアプリです。

## 機能

- 残量と目的から運用方針を判定
- 入力値を端末内に保存
- 結果をMarkdownでコピー
- スマートフォン表示対応
- PWA設定とService Workerを収録

## GitHub Pagesで公開

1. `Settings` → `Pages`
2. Sourceを `Deploy from a branch`
3. Branchを `main`、フォルダを `/(root)`
4. `Save` を押す
5. 数分後に表示されるURLをスマートフォンで開く

## ホーム画面に追加

- Android：Chromeの「ホーム画面に追加」
- iPhone：Safariの共有ボタンから「ホーム画面に追加」
